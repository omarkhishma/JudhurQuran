### Architecture
- [2026-10-02] **Next.js 16 App Router + React 19 + TypeScript for the web.** — SSR is required for verse/root/word pages (Arabic SEO is the clearest market gap per research 04), and the reader/editor are client-heavy.
- [2026-10-02] **Previous caching model (fetch revalidate + tags), not Cache Components; a release expires the `dataset` tag.** — Stable with next-intl's static rendering; content is immutable per release. The loader POSTs to the web's `/api/revalidate` (bearer `JADHR_REVALIDATE_SECRET` in production) which calls `revalidateTag("dataset", { expire: 0 })` — not stale-while-revalidate, because a release can change payload shape and stale pages then crash. API ETags hash `version@loaded_at`, re-read every 30 s, so a corrected rebuild of the same version never answers 304 with old content. A CDN in front must be purged on release (runbook).
- [2026-10-02] **Nothing is prerendered at build: every page renders on first request and is cached (ISR) until the next release expires it.** — A code deploy never needs the database or API, and the web image builds in CI with no data. First visits cost one render; all later ones are cached. Sitemap ids are fixed (capacity 80k words) for the same reason.
- [2026-10-02] **Production topology: Caddy in front (TLS, compression, `/api/v1` straight to FastAPI, `/api/revalidate` not public), Next standalone, Postgres; one-off loader container.** — Verified end to end on local Docker (docs/DEPLOY.md).
- [2026-10-02] **CSP allows inline scripts but no eval or third-party origin (audio from EveryAyah only).** — Next hydrates through inline scripts; a nonce would make every page dynamic and lose ISR.
- [2026-10-02] **FastAPI (Python) API + Python pipeline, separate from the web app.** — Owner suggested Python; the public API is a product (versioning, OpenAPI docs, own limits); the Arabic data tooling is Python. The browser reaches the API same-origin through a Next rewrite of `/api/v1/*`.
- [2026-10-02] **Search on Postgres (normalised shadow columns + pg_trgm), behind one module.** — Quran scale does not need a search cluster; all Arabic search assertions pass. Revisit when lexicon/hadith full-text relevance is measured to need OpenSearch.
- [2026-10-02] **Two Arabic search shadows: imlāʾī (KFGQPC "emlaey" text aligned per word) and Uthmani-stripped; the query picks one.** — Everyday spelling matches the imlāʾī shadow (الصلاة → ٱلصَّلَوٰة); text pasted from a mushaf (detected by dagger alef, wasla or Quranic marks) matches the Uthmani shadow. Lemmas also carry a heuristic plain spelling (وٰ→ا etc.) for matching only.
- [2026-10-02] **Graph canvas: @xyflow/react + elkjs, bounded expansion.** — The handoff editor is rich editable DOM cards; scale is handled by bounding, not a canvas renderer.
- [2026-10-03] **Every Quran permalink lands in the one reader: `/quran/{s}` reads, `/quran/{s}/{a}` opens the verse in the panel, `/word/{s:a:w}` opens the word; verse mode writes its path to the address bar, a word stays `?w=&at=` on the sūra.** — One reader, one URL behaviour (RDR-566). The sūra text, metadata, JSON-LD and share images render on the server; the panel's tafsir and entry render in the browser (search engines that run scripts index them). Rendering the panel on the server would need per-request state outside the module stores.
- [2026-10-03] **The reader's star writes to the one saved list (`jadhr-saved`, kind `lemma`, keyed by slug) that Saved, the Review count and later the Notebook read.** — The prototype kept stars under one key and read them under another (RDR-520).
- [2026-10-02] **Postgres 17 in Docker for dev (host 5442); web dev on port 3210, API on 8000.** — Match prod major; port 3000 belongs to another of the owner's projects.

## Lessons

- [2026-10-03] Match words in the Shamela typings with final yāʾ and alif-hamza folded: they write «والثانى»، «فى»، «الاول», so a marker list in standard spelling silently found the first aṣl and never the second. Build matchers from words through one helper that allows ي/ى, أ/ا and harakāt between letters.

- [2026-10-03] Never chain a commit after a test run piped through `grep`: the pipe's status is grep's, so two failing e2e tests let the commit through. Run the tests, read the result, then commit.

- [2026-10-03] The web's fetch cache outlives builds and restarts (`.next/cache`): an API endpoint whose payload changed shape keeps answering the page with the old shape for a day — /sources crashed on a missing field. After an API change on an existing URL, run `uv run python -m jadhr_api.loader --revalidate` against the server in use; a production server refuses without its `JADHR_REVALIDATE_SECRET`, so the local test server is started with a local one.

- [2026-10-03] Check the fonts against the text, not the text against the fonts: «عزّ وجلّ» (U+FDFF, Unicode 14) is in 1,809 dictionary articles and in neither Plex nor Amiri, so it drew as a box. A 10 KB subset of Noto Naskh Arabic (OFL) is now the last fallback, loaded only when such a character is on the page.

- [2026-10-03] A page under `[locale]` that reads `searchParams` must say `export const dynamic = "force-dynamic"`: the locale layout prerenders it, the build passes, and every request fails with DYNAMIC_SERVER_USAGE (a 500). The graph seed page did exactly that.

- [2026-10-03] A column flex container must not wrap: with `flex-wrap: wrap` each column line takes its content's width, so the concordance's chip rows grew to 1,140 px inside a 380 px bar and the phone's layout viewport widened to 1,167 px — every tap in the e2e run missed. The no-horizontal-scroll check caught it; keep it in every screen's phone test.
- [2026-10-03] Nothing a server component calls may be exported from a `"use client"` module: the server receives a reference, the build passes, and the page fails with a 500 at request time. Shared helpers and types go in `lib/`.
- [2026-10-03] KWIC columns line up only when every row shares one grid: separate grids per row size the keyword column per row. One grid with `subgrid` rows puts the keywords on one axis; the rows stay a list of links, because `role="row"` is not allowed on a link.

- [2026-10-03] Compare written vowels, and treat a sukun and a missing shadda as information: matching al-Rāghib's headwords on letters alone tied «العَلَمُ» (a sign) to عَلَّمَ (he taught) and «النَّفْرُ» to نَفَر; a vocalised letter without the other side's shadda, or a sukun against a vowel, rules the candidate out.
- [2026-10-03] Corpus lemma forms are not dictionary forms: some Form VIII verbs lose their alif («طَّلَعَ» for ٱطَّلَعَ), some derived verbs have no verb form at all («يُحَآدُّ»), and the mushaf's «آ» is a long alef with the madd sign («هَوَآء») where everyday spelling's «آ» is hamza + alef. Never read a missing form as Form I; fold per source.
- [2026-10-03] NFC composes ي + a hamza mark into ئ: a test literal that types the corpus's detached hamza next to its letter tests something else. Copy the source sequence, spaces included.
- [2026-10-03] A typing's line breaks are not paragraphs: the Shamela text breaks after «وجمعه:», before verse references and in mid-sentence.
