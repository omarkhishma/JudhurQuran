### Architecture
- [2026-10-02] **Next.js 16 App Router + React 19 + TypeScript for the web.** — SSR is required for verse/root/word pages (Arabic SEO is the clearest market gap per research 04), and the reader/editor are client-heavy.
- [2026-10-02] **Previous caching model (fetch revalidate + tags), not Cache Components; a release expires the `dataset` tag.** — Stable with next-intl's static rendering; content is immutable per release. The loader POSTs to the web's `/api/revalidate` (bearer `JADHR_REVALIDATE_SECRET` in production) which calls `revalidateTag("dataset", { expire: 0 })` — not stale-while-revalidate, because a release can change payload shape and stale pages then crash. API ETags hash `version@loaded_at`, re-read every 30 s, so a corrected rebuild of the same version never answers 304 with old content. A CDN in front must be purged on release (runbook).
- [2026-10-02] **Nothing is prerendered at build: every page renders on first request and is cached (ISR) until the next release expires it.** — A code deploy never needs the database or API, and the web image builds in CI with no data. First visits cost one render; all later ones are cached. Sitemap ids are fixed (capacity 80k words) for the same reason.
- [2026-10-02] **Production topology: Caddy in front (TLS, compression, `/api/v1` straight to FastAPI, `/api/revalidate` not public), Next standalone, Postgres; one-off loader container.** — Verified end to end on local Docker (docs/DEPLOY.md).
- [2026-10-02] **CSP allows inline scripts but no eval or third-party origin (audio from EveryAyah only).** — Next hydrates through inline scripts; a nonce would make every page dynamic and lose ISR.
- [2026-10-02] **FastAPI (Python) API + Python pipeline, separate from the web app.** — Owner suggested Python; the public API is a product (versioning, OpenAPI docs, own limits); the Arabic data tooling is Python. The browser reaches the API same-origin through a Next rewrite of `/api/v1/*`.
- [2026-10-02] **Search on Postgres (normalised shadow columns + pg_trgm), behind one module.** — Quran scale does not need a search cluster; all Arabic search assertions pass. Revisit when lexicon/hadith full-text relevance is measured to need OpenSearch.
- [2026-10-02] **Two Arabic search shadows: imlāʾī (KFGQPC "emlaey" text aligned per word) and Uthmani-stripped; the query picks one.** — Everyday spelling matches the imlāʾī shadow (الصلاة → ٱلصَّلَوٰة); text pasted from a mushaf (detected by dagger alef, wasla or Quranic marks) matches the Uthmani shadow. Lemmas also carry a heuristic plain spelling (وٰ→ا etc.) for matching only.
- [2026-10-02] **Graph canvas: @xyflow/react + elkjs, bounded expansion.** — The handoff editor is rich editable DOM cards; scale is handled by bounding, not a canvas renderer.
- [2026-10-03] **Every Quran permalink lands in the one reader: `/quran/{s}` reads, `/quran/{s}/{a}` opens the verse in the panel, `/word/{s:a:w}` opens the word; verse mode writes its path to the address bar, a word stays `?w=&at=` on the sūra.** — One reader, one URL behaviour (RDR-566). The sūra text, metadata, JSON-LD and share images render on the server; the panel's tafsir and entry render in the browser (search engines that run scripts index them). Rendering the panel on the server would need per-request state outside the module stores.
- [2026-10-03] **The reader's star writes to the one saved list (`jadhr-saved`, kind `lemma`, keyed by slug) that Saved, the Review count and later the Notebook read.** — The prototype kept stars under one key and read them under another (RDR-520).
- [2026-10-02] **Postgres 17 in Docker for dev (host 5442); web dev on port 3210, API on 8000.** — Match prod major; port 3000 belongs to another of the owner's projects.

### Data
- [2026-10-02] **Display text = official KFGQPC Hafs data v2.0 (`hafsData_v2-0.json`), byte-identical; font = KFGQPC Uthmanic Hafs V22 (signed TTF, unmodified).** — Direct from the Complex (MD5/SHA-1 match its published checksums), with Madinah page and line numbers and an official imlāʾī search text. Rendering test: Tanzil text with this font shows a broken dotted-circle glyph (e.g. 7:195) and no pause marks; the KFGQPC text renders like the printed mushaf. The copy previously obtained via QUL/Quran.com was deleted (Quran Foundation terms forbid storing beyond one week).
- [2026-10-02] **The ayah-end medallion is drawn from Arabic-Indic digits, not the file's ayah-mark code point.** — The official text ends each verse with a font-specific code point (U+FC00 + ayah − 1) that renders as an unrelated ligature if the font fails; digits render identically with the font and degrade safely. The stored verse text keeps the code point verbatim.
- [2026-10-02] **Pages and lines from KFGQPC; juz from Tanzil.** — The KFGQPC JSON's juz field starts juz 4 at 3:92 and juz 11 at 9:94, contradicting the ۞ signs printed in its own text at 3:93 and 9:93 (a juz must start on a hizb boundary); Tanzil's juz table agrees with the printed signs. 56 page boundaries differ from Tanzil's older print; KFGQPC's numbering matches the edition we display.
- [2026-10-02] **Morphology: Quranic Arabic Corpus v0.4 as primary, unchanged; v2 (author's revision) and the mustafa0x fork stored as attributed root variants, never merged silently.** — Every other root dataset tested descends from QAC (research 01). Differences are classic scholarly disputes (الناس نوس/أنس, نادى ندو/ندي) and must be shown, not hidden.
- [2026-10-02] **Particles, pronouns and foreign proper nouns show "no root" — never a pseudo-root.** — The owner's example CSV gives 27,462 such words pseudo-roots (من → "م ن"); 49,085 CSV roots agree with QAC and 882 differ.
- [2026-10-02] **Tafsir launch set: al-Muyassar and al-Mukhtasar (QuranEnc, explicit re-publication grant), al-Sa'di (QUL 308), al-Baghawi, Ibn Kathir, al-Qurtubi, al-Tabari (public-domain authors; text via tafsir_api v1.2.2).** — Passages regrouped from the mirror's per-ayah copies. The digital editions of al-Baghawi, Ibn Kathir, al-Qurtubi and al-Tabari print their modern editors' footnotes inline (`[[…]]`) and al-Baghawi's carries manuscript folio marks; both are stripped at build (2026-10-03, D22) by a bracket-aware stripper — the author's text only, with ordinary editorial brackets around restored words kept. Report: `works.<id>.apparatus_removed`.
- [2026-10-02] **English: Saheeh International and Rowwad via QuranEnc.** — Only explicitly re-publishable English found; Tanzil translations are non-commercial and non-redistributable; Yusuf Ali carries US risk.
- [2026-10-02] **Audio plan: EveryAyah verse audio + quran-align word timings (CC BY 4.0); word pronunciation = the word's slice of the verse audio.** — Per-word MP3s on Quran.com's CDN have no license.
- [2026-10-02] **Morphological pattern (wazn) per lemma, three layers, abstain unless certain (`pipeline/.../wazn.py`).** — Verb forms and tagged derivatives get the pattern of their form; Form I gets its middle vowel only from a perfect-tense lemma; other nouns are matched letter by letter against the root and accepted only if exactly one pattern from a closed classical list fits. Pattern is stated on the underlying form before iʿlāl (قَالَ فَعَلَ، مِيزَان مِفْعَال، مَقَام مَفْعَل), as in the sarf books. Result over 4,657 rooted lemmas: tag 927, verb form 1,045, letter match 2,121, Form I without vowel 429, none 135 (7.5% of rooted occurrences, mostly ٱللَّه and deleted-radical nouns like يَد، ابْن). Stored with `pattern_method` so the UI says how each was found. Top 260 matched nouns reviewed by hand; expert linguistic review still owed. No per-pattern "meaning" text is generated — that must come, credited, from sarf books.
- [2026-10-02] **English: word glosses and transliteration verbatim from the corpus Word by Word pages (fetched politely, pages kept with sha256); lemma glosses from the corpus author's revision (GPL-3.0, mostly verbs).** — Display with credit and link is allowed; changes are not, so punctuation stays. MASAQ was rejected as a source: its glosses are the corpus glosses lowercased and hyphenated (97.6% of 77,015 words against the live corpus; 99.8% against the older copy in the owner's file — DATA-VALIDATION §4). The owner's file itself differs from the corpus in 2,065 words, mostly truncated glosses. Nouns get no lemma gloss rather than one we wrote.
- [2026-10-02] **Lexicon articles are shown only for confidence exact, manual or high; approximate root mappings stay hidden until reviewed.** — 1,060 mappings are approximate (hamza/weak-letter spelling); 779 "high" ones are shown with a caveat.
- [2026-10-02] **Classical Arabic lexica launch display-only (al-Mufradat, Maqayis, Lisan, al-Sihah from the Shamela text, editor notes stripped); Lane (Perseus, CC BY-SA) is the only redistributable lexicon.** — Research 02.
- [2026-10-03] **Licence register: `data/licences.yaml`, one entry per source id in the four registries, each with the governing clauses quoted verbatim, the sha256 of every page read, our use and a status; re-checked before every release; `pipeline/tests/test_licences.py` fails when a registry id has no entry.** — Licence wording lived in scattered registry lines and research prose and had drifted from the sources (research 07); one register, checked by a test, keeps it honest.
- [2026-10-03] **Relation seeds (P8.4, P3.1) are parsed from four OpenITI 2025.1.9 files (commit cfc4157), every row a verbatim slice of the cleaned file with its locator, status `extracted` — never `reviewed`; registry `data/relations.yaml`, module `pipeline/.../relations/`.** — L2: a relation is shown only with the classical work, page and words behind it; editors review in the workbench. Headwords map to roots only mechanically, the method stored per row; quotations resolve to verses only when the Quran text decides (unique run, unique in the named sūra, or one place holding three quarters of the words), else `ambiguous`/`unresolved`. CC BY-NC-SA 4.0 per D18.
- [2026-10-03] **al-Furūq is read from OpenITI's `Shamela0010414` version, not the `JK006960` the metadata flags primary.** — The same typing of the same edition (identical slips), but it carries the edition card (editor Muḥammad Ibrāhīm Salīm; JK006960 has none, author death «9999»), page markers that follow shamela.ws book 10414, a few corrections and no stray conversion marks. JK006960 stays pinned as a cross-check.

## Lessons

- [2026-10-03] Never reveal content on `:focus-within` above a tappable element: a tap focuses the button on mousedown, the revealed tools pushed the word down, and the click landed on the verse instead — every phone tap was lost. Reveal on hover, `:focus-visible` or an explicit state.
- [2026-10-03] A portal into server-rendered DOM needs a flag set after the first commit, not "is client": after a client-side navigation the client flag is already true during the first render, when the new page's DOM does not exist yet.
- [2026-10-03] Esc belongs to the innermost layer: a page-level Esc handler must stand down while any dialog or term card is open, or one keypress closes the card and the entry behind it.

- [2026-10-03] Check the licence of the repository the bytes come from, not a sibling repository by the same author: the corpus revision's files sit in an unlicensed API repository while our registry cited the GPL of its frontend.
- [2026-10-03] Read the files' own tags, not only the distributor's licence page: EveryAyah's ID3 tags name QuranicAudio.com (personal use only), MP3Quran.net and AllahsQuran.com as origins of some recordings.
- [2026-10-02] Strict parsers turn silent corruption into loud failures — the QAC v0.4 file ships with CRLF; the parser accepts consistent CRLF and rejects any stray CR.
- [2026-10-02] Never compare Arabic combining-mark strings as typed literals — editors reorder marks. Compare after NFC (canonical order) or assert codepoint escapes; inside the wazn engine, shadda is moved before the vowel so suffixes like ـِيُّون compare letter by letter.
- [2026-10-02] A word can contain two stems (وَمِمَّا = و + مِن + مَا, 486 words) — features live per stem and the word exposes a primary stem (first with a root, else first content word).
- [2026-10-02] QAC writes a hamza radical as `A` (Amn, sAl, qrA) — map to ء; display it as أ (dictionary convention).
- [2026-10-02] Unlayered CSS beats Tailwind 4 utilities (which live in `@layer utilities`) — component recipes must sit in `@layer components` or responsive utilities like `max-sm:hidden` silently lose.
- [2026-10-02] A URL-sync effect that runs on the initial render wipes `?w=` before it is read under React strict mode — only write the URL after the panel actually changes.
- [2026-10-02] A `str.replace` patch whose target text drifted (a formatter rewrapped it, or literals differ in mark order) fails silently — patch scripts assert the match count first. Bit twice: the loader's truncate list and the wazn preprocessing.
- [2026-10-03] An inline footnote can begin in one verse's text and close in the next, and a footnote can hold bracketed references (`[[… [فصلت: ١٠]]]`): a regex stripper either leaves debris or eats the author's text. Track bracket depth.
- [2026-10-02] A comment that claims a mechanism exists is not evidence — `api.ts` said pages "are invalidated through the dataset tag when a release loads" while nothing called it; the root page then crashed on a cached pre-lexicon payload. Verify claims in comments against code.
- [2026-10-02] A root `not-found` that redirects turns every broken link into a 307 to the home page (soft-404, wrong language for `/en/...`). Unknown paths need `[locale]/[...rest]` → `notFound()`.
- [2026-10-02] The loader's truncate list must cover every loaded table (a startup guard now fails otherwise) — a reload once duplicated lexicon rows.
- [2026-10-02] The Sudais timing file in the quran-align release has a crash log prepended — recovered from the first `\n[` and recorded as `recovered_after_crash_log`; never "fix" sources silently.
- [2026-10-02] Corpus verb lemmas are not always perfect forms (يَعْلَمُ، لَقُ) — reading the middle vowel from them gave ~220 wrong فَعَلَ/فَعِلَ claims before the perfect-only rule.
- [2026-10-02] Run the production build before calling a web change done: dev mode hid five production bugs at once (pages rendering per request because a layout lacked `setRequestLocale`, search crashing as a static page, the `/api/v1` rewrite baked at build, a locale cookie defeating CDN caching, a redirect loop).
- [2026-10-02] Docker sets `HOSTNAME` to the container id; Next standalone then treats the locale proxy's internal rewrite as an external host and every Arabic page redirect-loops. The image sets `HOSTNAME=0.0.0.0`.
- [2026-10-02] Next's image renderer (Satori) shapes Arabic letters but neither reorders right-to-left runs nor places Quranic marks, and it measures joined words as if unjoined. Share images carry no Quranic text and lay out pre-shaped presentation forms word by word.
- [2026-10-02] A `pytest_collection_modifyitems` hook in a sub-directory conftest receives every test of the session — filter to its own directory or it skips unrelated tests.
- [2026-10-02] Search responses are cached in the web app for an hour; an API behaviour change needs `loader --revalidate`, not only a data release.
- [2026-10-02] Measure progress against the source of truth (vision + design inventory), not against a plan I wrote myself — a reduced plan makes "done" meaningless.
- [2026-10-02] Dataset cards contradict themselves: the Shamela 4 card's YAML says `license: mit` while its own licence section says "Research and personal use". Read the whole card and the upstream terms, never just the tag.
- [2026-10-02] Licence labels on derived datasets often relicense what the packager never owned (MIT on recitation audio cut from EveryAyah, CC0 on OpenITI chunks, CC BY on CC BY-NC-SA text). Trace every layer to its origin before trusting a label.
- [2026-10-02] File names lie: `tanzil/quran-uthmani.txt` is byte-identical to the no-pause-marks file. Verify content (for example, count the pause marks) before pinning a file under a name.
- [2026-10-02] Prototype data is not content: the handoff's senses, sense-to-dictionary marks, articles and timeline dots are placeholders or hashes, and its sample data has linguistic errors. Use it as a UI fixture only.
- [2026-10-02] Every subagent prompt must forbid identifying data in outgoing requests — one research helper put the owner's email in a User-Agent header on a public query.
- [2026-10-03] Write `\uXXXX` escapes in Python sources as `chr(0x…)`: a file-writing tool turned them into the literal characters, leaving invisible combining marks inside regex classes. Scan new sources for category Mn/Cf characters before committing.
- [2026-10-03] A matching rule that sounds right can lose: folding a leading «ف» and a final open taa into the quotation key resolved fewer quotations on the four works (6,963 vs 7,001). Measure each rule on the real corpus before keeping it.
- [2026-10-03] A rename leaves the old name in places a source search never looks: compiled caches (`__pycache__`, ruff, mypy), the virtualenv prompt, the dev server's build cache. An absence check walks every file on disk, not only tracked ones, with a planted positive control.
